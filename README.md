# 热量记录 · Calorie Tracker

一个为手机设计的每日热量记录工具。算出你的基础代谢和每日摄入上限,记录每餐吃了什么,
自动扣除并显示**还能吃多少**,同时帮你把剩余热量分配到接下来的几餐。

纯静态单页,无需后端、无需账号,所有数据保存在你自己手机的浏览器里。

## 功能

- **每日上限**:按 Mifflin-St Jeor 公式计算基础代谢(BMR),乘活动系数得总消耗(TDEE),再按减脂/维持/增重目标得出每日上限。也可手动指定。
- **逐餐记录**:早餐 / 午餐 / 晚餐 / 加餐分开记录,内置 100+ 常见食物的热量,输入克数自动换算;按份计的食物(鸡蛋、奶茶、汉堡等)直接填份数。
- **实时剩余**:顶部圆环显示今天还剩多少 kcal,超出时变红并显示超了多少。
- **三餐分配**:按百分比把上限分到各餐,每餐独立进度条;并根据还没吃的餐次,给出剩余热量的分配建议。
- **智能提醒**:快吃到上限、已超标、某餐忘记记录、当餐时间到了、晚上吃太少,都会有对应提示。
- **历史趋势**:最近 14 天柱状图、日均摄入、超标天数。
- **自定义食物**:记录库里没有的食物时会自动按 100g 折算并存下来,下次直接搜到。
- **数据导出 / 导入**:JSON 格式,换手机不丢数据。
- **离线可用**:Service Worker 缓存,装到主屏幕后断网也能记。

## 使用

### 在手机上用(推荐)

发布到 GitHub Pages 后,用手机浏览器打开,再「添加到主屏幕」,就会像一个独立 App 一样打开(无地址栏、可离线)。

### 本地直接用

双击 `index.html` 即可。注意:以 `file://` 打开时浏览器不允许注册 Service Worker,离线缓存不生效,其他功能正常。

想在本地完整测试(含离线),起一个静态服务器:

```bash
npx serve .
```

## 发布到 GitHub Pages

```bash
git remote add origin https://github.com/jinriwen/WeightCheck.git
git push -u origin main
```

推送后在仓库页面:**Settings → Pages → Source 选 `Deploy from a branch` → 分支选 `main`、目录选 `/ (root)` → Save**。
等一两分钟,访问 `https://jinriwen.github.io/WeightCheck/` 即可。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 整个应用(HTML + CSS + JS,单文件) |
| `manifest.webmanifest` | PWA 配置,决定「添加到主屏幕」后的名称和图标 |
| `sw.js` | Service Worker,负责离线缓存。**改动文件后记得把里面的 `VERSION` 加 1** |
| `icons/` | 应用图标 |
| `tools/make-icons.mjs` | 重新生成图标:`node tools/make-icons.mjs`(纯 Node,无依赖) |

## 数据存在哪

浏览器的 `localStorage`,键名 `calTracker.v1`。它**不会上传到任何服务器**,但也意味着:

- 清除浏览器数据 / 缓存会一并删掉记录 —— 建议偶尔用「导出数据」备份一次;
- 换浏览器或换手机,需要用导出的 JSON 「导入数据」。

## 说明

内置热量为常见参考值(每 100g 或每份),用于日常估算,会因品牌、做法、油盐用量而有出入。
